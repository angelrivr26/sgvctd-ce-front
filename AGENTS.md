# Instrucciones del frontend Comprobantes

- Mantener Angular y la organizacion core, modules y shared. Separar HTTP de componentes de pantalla.
- Cada cambio tambien actualiza ../backend-comprobantes/BITACORA.md con alcance, motivo y validacion.
- Mostrar de forma explicita que los comprobantes son simulados. No incluir credenciales de integracion en el navegador.
- Mantener estados de carga, error y vacio, acceso por teclado, etiquetas de formularios y diseno adaptable.
- Ejecutar npm run build y las pruebas aplicables. Mantener package-lock.json y auditar cambios de dependencias.
